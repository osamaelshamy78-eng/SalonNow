# SalonNow

SalonNow is a standalone salon discovery and live-queue MVP.

## Phase 1
- Customer Men/Women discovery
- Salon profiles
- Salon-owned services and prices
- Live queue status
- Estimated waiting time
- Salon dashboard for walk-ins and queue updates

## Important
This project is completely independent from Karaji/Sayyarti.

There are no payments, commissions, subscriptions, or monetization in Phase 1.
